# Nirmal Ganesh — Portfolio

A single-file static site (`index.html`): no build step, no dependencies.

Features: interactive terminal (type `help`), animated neural-network background,
curiosity timeline, AI exploration cards, side projects, and a clickable luck formula.
Light/dark theme toggle included.

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy free on Render

1. Push this folder to a new GitHub repo (e.g. `nirmalganesh15/portfolio`).
2. On https://dashboard.render.com → **New → Blueprint** → pick the repo.
   `render.yaml` creates a free **Static Site** automatically.
   (Or **New → Static Site**, build command empty, publish directory `.`)
3. You get a URL like `https://nirmal-portfolio.onrender.com`.

Static sites on Render are free and don't sleep.

## Other free options

- **GitHub Pages**: repo Settings → Pages → deploy from `main` / root.
- **Netlify / Vercel**: drag-and-drop the folder, or import the repo.
